# PasteWin

Windows 版 [Paste](https://pasteapp.io) 剪贴板管理器。按 `Ctrl+Shift+V` 从屏幕底部滑出卡片面板,
搜索、浏览、回车即把内容粘回你刚才所在的窗口。

├──────────────────────────────────────────────────────────────┤

## 功能

**捕获** — 后台常驻,自动记录复制的文本、图片、文件列表、富文本(HTML/RTF)。
内容按 hash 去重,重复复制同一条只会把它提到最前,不会堆出重复卡片。

**面板** — `Ctrl+Shift+V` 唤出,贴在鼠标所在显示器的底部。横向卡片流,最近优先。

| 按键 | 动作 |
|---|---|
| `←` `→` | 浏览 |
| `Enter` | 回贴到唤起前的窗口 |
| `Shift+Enter` | 以纯文本回贴(去掉格式) |
| `Ctrl+1`…`9` | 快速回贴第 N 条 |
| `Ctrl+P` | 置顶 / 取消置顶 |
| `Ctrl+E` | 就地编辑 |
| `Ctrl+B` | 移动到分组 |
| `Delete` | 删除 |
| `Esc` | 收起面板(搜索框非空时先清空搜索) |
| 鼠标滚轮 | 左右滚动卡片(纵向滚轮自动转成横向) |
| 点击面板外 | 收起面板(面板失去焦点即自动收起) |

> 面板弹出后搜索框自动获得焦点,可以直接打字过滤;
> 方向键、`Enter`、`Esc` 与 `Ctrl` 组合键始终由面板处理,不会被输入框吞掉。

**分组(Pinboard)** — 长期保存常用内容,不受历史上限清理影响。

**隐私** — 排除名单里的应用(如密码管理器)复制的内容不记录;
同时识别来源应用主动标记的敏感内容(`ExcludeClipboardContentFromMonitorProcessing`)。

**托盘** — 常驻通知区域,左键唤起面板,右键菜单可暂停捕获、打开设置与数据目录、退出。

**其他** — 历史上限可配(默认 2000 条,超出后清理最旧的未置顶条目)、开机自启、数据全在本地。

## 快速开始

**从源码构建并运行**

```bash
./build.sh
./build/bin/PasteWin.exe
```

**安装到本机**(per-user,不需要管理员权限)

```bash
./install.sh                 # 安装 + 开启自启 + 启动
./install.sh --no-autostart  # 装完不自启
./uninstall.sh               # 卸载,保留历史数据
./uninstall.sh --purge       # 连数据一起删
```

安装位置:

| 内容 | 路径 |
|---|---|
| 程序 | `%LOCALAPPDATA%\Programs\PasteWin\PasteWin.exe` |
| 数据 | `%LOCALAPPDATA%\PasteWin\`(`pastewin.db` + `blobs\`) |
| 快捷方式 | 开始菜单 → PasteWin |
| 自启项 | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |

安装后程序常驻通知区域(不显示主窗口)。按 `Ctrl+Shift+V` 唤出面板,
复制任意内容后回到面板即可看到记录。

**命令行**

```bash
PasteWin.exe           # 启动;若已在运行则唤起其面板
PasteWin.exe --quit    # 让正在运行的实例优雅退出
```

同一时刻只会有一个实例在跑 —— 重复启动不会产生多余的托盘图标。

## 环境要求

- Windows 10/11(需要 WebView2 运行时,Win11 自带)
- 构建需要 Go 1.27+、Node.js、Wails CLI

`build.sh` 已封装本机环境的全部配置(Go 路径、goproxy.cn、`CGO_ENABLED=0`、跳过慢速绑定生成)。
细节与原因见 [DESIGN.md](DESIGN.md) 第 9 节。

## 与 macOS 原版的差异

- **Paste Stack** 实现为「按顺序逐条粘贴」,而非原版的「每次 `Cmd+V` 粘出下一条」。
  后者需要低级键盘钩子拦截 `Ctrl+V`,属有意取舍,详见 DESIGN.md 7.1。
- 无 iCloud 跨设备同步、无 OCR 搜索、无团队共享分组。

## 已知限制

- 对以管理员权限运行的窗口,`SendInput` 可能无效。此时内容仍在剪贴板里,手动 `Ctrl+V` 即可。
- 无边框窗口不支持拖拽调整大小;面板高度在设置里配置。
